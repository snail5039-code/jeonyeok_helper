# 전역도우미 (jeonyeok_helper) 기획서

> 전역자가 자기 상황을 말하면 **받을 수 있는 혜택, 근거 규정, 신청처**를 한 번에 알려주는 AI 에이전트

---

## 1. 왜 만드나
- 전역자는 받을 수 있는 혜택을 잘 모른다.
- 규정 문서는 길고 여러 곳에 흩어져 있다.
- 혜택을 알아도 어디서 어떻게 신청하는지 다시 찾아야 한다.

## 2. 무엇을 하나
| 기능 | 설명 |
|---|---|
| 규정 Q&A | 법령과 보훈부 자료를 검색(RAG)해서 **근거 조문과 함께** 답변 |
| 맞춤 혜택 찾기 | 복무 형태, 기간, 나이, 지역으로 공공서비스 API를 조회해 해당 혜택만 추림 |
| 기관 연계 | 혜택마다 소관 기관, 신청 방법, 링크, 연락처 안내 |

**사용 예시**
> "작년 12월에 병장으로 만기 전역했고, 서울 살아요. 받을 수 있는 거 있어요?"
> → 군복무 크레딧(국민연금법 제18조), 서울시 청년 지원, … + 신청 링크

## 3. 대상 사용자 ✅ 전체 유형
| 유형 | 혜택 차이 |
|---|---|
| 의무복무 전역자 (병사) | 군복무 크레딧, 지자체 청년 지원 등 |
| 단기 간부 (5년 미만) | 일부 취업 지원 |
| 중·장기 제대군인 (5년, 10년 이상) | 제대군인지원법상 전직 지원 등 |
| 보훈대상자 | 보훈부 지원 전반 |

- 유형마다 혜택이 크게 다르므로 **프로필(복무 형태, 기간)로 먼저 유형을 가린 뒤** 해당 혜택만 안내한다.
- 프로필은 **대화 중에 묻는다.** 프로필 에이전트가 답변에 필요한 정보가 빠졌을 때만 되묻고, 받은 정보는 장기 메모리에 저장한다.

## 4. 데이터
| 구분 | 내용 | 수집 방법 |
|---|---|---|
| 법령 | 제대군인지원법, 국가유공자법, 보훈보상대상자법, 병역법, 군인연금법, 국민연금법(군복무 크레딧) | 국가법령정보센터 API |
| 행정 문서 | 국가보훈부 안내 자료 | 파일 업로드 (PDF 등) |
| 지자체 조례 ✅ MVP 포함 | 시·도별 전역 청년 지원 조례 | 국가법령정보센터 API (자치법규) |
| 실시간 혜택 | 대한민국 공공서비스(혜택) 정보 | 공공데이터포털 API |

## 5. 구조
```
사용자 ─▶ FastAPI ─▶ 슈퍼바이저 (Gemini, LangGraph)
                        ├─ 프로필 에이전트   : 부족한 정보 되묻기
                        ├─ 규정 에이전트     : RAG 검색 → 근거 조문
                        ├─ 혜택 에이전트     : MCP → 공공서비스 API
                        └─ 기관연계 에이전트 : 신청처, 링크, 연락처
                     ─▶ 근거 검증 (Reflection) ─▶ 답변 (SSE 스트리밍)
```

## 6. 기술 스택 (AI.M 1기 AI 에이전트 엔지니어 트랙 기준)
| 영역 | 기술 |
|---|---|
| LLM | Gemini |
| 에이전트 | LangChain (LCEL), **LangGraph 멀티에이전트**, ReAct |
| 평가 | **평가 데이터셋** 30문항 (근거 출처, 답변 핵심어, 프로필, 되묻기 채점) |
| 도구 연동 | **MCP 서버** (공공 API, 법령 검색) |
| RAG | pgvector(처음엔 Chroma), 조문 단위 청킹, **HyDE**, **Re-ranking** |
| 서버 | **FastAPI** (비동기, SSE 스트리밍), SQLite (대화 기록·프로필) |
| 화면 | **Next.js 16** (App Router, TypeScript, Tailwind CSS) |
| 배포 | **Docker**, **AWS**, **GitHub Actions** CI/CD |
| 선택 | A2A, Standardized Skills, LoRA 파인튜닝 |

## 7. 일정
| 단계 | 할 일 | 결과물 |
|---|---|---|
| 1 | 법령 수집, RAG 구축 | 규정 검색이 되는 상태 |
| 2 | 공공 API를 MCP 서버로 연동, 기관 링크 정리 | 혜택 조회 도구 |
| 3 | LangGraph 슈퍼바이저와 워커 | 에이전트 MVP |
| 4 | FastAPI, 웹 UI | 실제로 써볼 수 있는 서비스 |
| 5 | 평가(질문 30개), Docker, AWS, CI/CD | 배포된 서비스 |

## 8. 리스크
| 리스크 | 대응 |

| 법령 개정, 사업 변경 | 시행일과 조회일 표시, 정기적으로 다시 수집 |
