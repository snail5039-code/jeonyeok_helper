# 추가할 자료와 API (2026-10-13 조사)

웹 검색으로 전역자 혜택을 분야별로 다시 찾고, 지금 DB(10,142조각)에 있는지 본문 검색으로 대조했다.
**DB 상태**는 `langchain_pg_embedding.document`에 그 낱말이 있는지로 판단했다 (있어도 내용이 오래됐을 수 있음).

넣는 방법 약어
- **웹**: 공식 안내 페이지를 `backend/data/webpages.yaml`에 넣고 `uv run jeonyeok-rag web`
- **PDF**: 받은 파일을 `backend/data/raw/`에 넣고 `jeonyeok-rag files` (add-data 스킬 절차)
- **API**: 새 도구(`benefits/`) 추가, 키는 `.env`
- **실시간**: 정부24·온통청년 API에 이미 있을 수 있어 검색어가 닿는지 먼저 확인

## 금융

### 히어로즈 카드 — DB 없음 ★
- **대상**: 만 34세 이하 제대군인, 또는 나이 상관없이 전역 후 3년 이내 제대군인. 전역 전에는 신청 불가
- **내용**: 체크카드(연회비 없음). 학원·서점, 어학시험 응시료, 통신, 철도·고속버스, OTT 등 5~20% 할인.
  카드사마다 전월 실적·할인 한도가 다름 (IBK 예: 전월 20만 원 이상, 월 1만 5천 원 한도)
- **신청**: IBK기업은행(I-히어로즈), KB국민카드, NH농협카드에서. 보훈부에 신청하는 것 아님.
  전역 정보는 공공 마이데이터로 확인하는데 전역 후 반영까지 약 1개월 걸릴 수 있음
- **출시**: 2024년 7월, 국가보훈부 기획
- **출처**: [복지로](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/news/promotion/1306923_1118.html), [이투데이](https://www.etoday.co.kr/news/view/2374892)
- **할 일**: 보훈부 또는 카드사 공식 안내 페이지를 찾아 웹으로. 로드맵 '전역 직후' 단계 후보

### 청년미래적금 — DB 없음 ★

- 월 50만 원까지, 3년 만기, 정부 기여금 일반 6% / 우대 12% (중소기업 재직자·신규 취업자 등)
- 1차 신청(6/22~7/3) 끝남, 2차는 12월 잠정
- **출처**: [헤럴드경제](https://www.heraldk.com/article/2026042222345653314)
- **할 일**: 정부24·온통청년 API에 있는지 먼저 확인. 없으면 금융위원회 안내 페이지를 웹으로

## 교육·자격

### 고용24 오픈API — 국민내일배움카드 훈련과정 ★
- 고용24 누리집 Open-API 소개에서 제공 목록을 직접 확인함:
  국민내일배움카드 훈련과정(목록·과정/기관정보·훈련일정), 채용정보, 공채속보, 정부지원일자리정보,
  구직자취업역량 강화프로그램, 청년친화강소기업, 직업정보, 학과정보 등
- 원래 기업회원 전용이었는데 '워크넷 OPEN-API 개인회원 개방' 공지가 있음. **담당자 심사 후 인증키 발급**
- 신청: 고용24 로그인 → 고객센터 → OPEN-API → 서비스 소개 및 신청
- DB에는 내일배움카드가 안내서 속 언급으로만 있고, 실제 과정 검색은 불가

### Q-Net 국가자격 API
- 공공데이터포털: 국가전문자격 시험 시행일정 [15003027](https://www.data.go.kr/data/15003027/openapi.do),
  국가자격 종목 정보 [15068022](https://www.data.go.kr/data/15068022/openapi.do) 등
- 기존 `DATA_GO_KR_SERVICE_KEY`로 활용신청만 추가
- 국가**기술**자격(기사·기능사) 시험일정 전용 API는 못 찾음. 신청 전에 상세 페이지 확인
- 쓰임: 자격증 질문, '군 특기 → 자격증' 추천

### 이미 있음 (참고)
- 군 원격강좌 학점 복학 후 인정, 복무 중 학자금 대출 이자 면제 (병 복지 길라잡이)
- 제대군인 직업능력개발교육비, 교육지원(학비), 취업맞춤특기병 (보훈부 교육훈련지원 페이지)
- 국가장학금·학자금 (장학금 공공데이터, 정부24)

### 확인 안 됨 — 넣지 말 것
- 군 특기 경력을 국가기술자격 응시 경력으로 인정하는 기준: 공식 근거를 못 찾음 (Q-Net 문의 필요)

## 의료·건강·심리

### 보훈 등록 전 진료비 — 일부만 있음
- 복무 중 다쳐서 국가유공자·보훈보상대상자 **등록을 신청하면 결정 전에도** 보훈·위탁병원 진료 가능
- **전역 6개월 이내에 등록 신청**하면 전역 다음 날부터 결정 전까지 진료비 지원 → 기한이 있는 핵심 정보
- DB에는 관련 법령해석만 있음
- **출처**: [로앤윈 정리](https://www.lawwin.co.kr/knowledge/8195) (2차 자료) → 보훈부 공식 안내로 확인 후 넣기
- **할 일**: 보훈부 '등록 전 진료' 안내 페이지 찾아 웹으로. 로드맵 '전역 직후' 핵심 후보 (due_months=6)

### 청년 마음건강 바우처 / 전국민 마음투자 지원 — DB 없음
- 전문 심리상담 8회 내외. 지자체·연령 기준(19~34 또는 39세)이 자료마다 다름. 복지로 신청
- 위기 상담: 1393(자살예방), 1577-0199(정신건강 위기)
- **출처**: [서울시 복지 누리집](https://news.seoul.go.kr/welfare/archives/562723)
- **할 일**: 정부24·온통청년에 있는지 먼저 확인. 위기 상담 번호는 기관 목록(`institutions.yaml`)에 추가 검토

### 복무 중 생긴 중증·난치 질환 진료비 감면 (보훈대상 아닌 제대군인) — 조문만 있음 ★
- 군 복무 중 발병·악화됐지만 **공무와 인과관계가 없어 국가유공자·보훈보상대상자가 못 된** 제대군인 대상.
  보훈병원·위탁병원 진료비 본인부담 50% 감면 (2008년 시작, 2018년 위탁병원까지 확대하는 개정 통과 보도)
- 대상 질환 **238개** (암, 재생불량성 빈혈, 심장질환, 만성신부전, 중증 정신질환, 파킨슨병 등)는 시행령 **별표**에 있음
- 신청: 관할 보훈(지)청, 보훈상담센터 1577-0606
- DB: 제대군인지원법 제20조, 시행령 제23조(감면비율)는 있음. **별표(질환 목록)는 수집됐는지 확인 필요**
  (법령 수집기가 별표를 안 가져올 수 있음 → `rag/law_api.py` 확인)
- 자료마다 대상이 '10년 이상 장기복무'로도 쓰여 있어 시행령 원문으로 대상 범위 확인할 것
- **출처**: [서울신문 2018](https://m.go.seoul.co.kr/news/2018/11/28/20181128014010), [국가보훈부 생활안정지원](https://mpva.go.kr/mpva/contents.do?key=139)
- 쓰임: "군대에서 생긴 병 전역 후 치료비 지원돼요?" 같은 질문 — 병사도 해당할 수 있어 중요

### 준보훈병원 (2026 신설) — DB 없음
- 보훈병원이 없는 강원·제주에 강원대병원·제주대병원을 첫 준보훈병원으로 지정, 2026년 12월 진료 시작 보도
- 보훈대상자·장기복무 제대군인 등이 이용
- **출처**: [뉴스1](https://www.news1.kr/amp/diplomacy/defense-diplomacy/6241007), [데일리팜](https://dailypharm.com/user/news/340935)
- **할 일**: 보훈부 공식 보도자료로 웹. `find_hospitals`(위탁병원 API)에 안 나오면 기관 목록에 추가 검토

### 전역 후 건강보험 자격 — DB 없음, 공식 근거 못 찾음
- 복무 중에는 군 의료라 건강보험 급여가 정지됨 → 전역 후 직장·지역·피부양자로 자격이 다시 잡힘.
  지역가입자면 다음 달부터 보험료 고지 (블로그 자료)
- 신고가 필요한지, 기한, 전역 후 건강검진 대상 여부는 **확인 못 함** → 국민건강보험공단(1577-1000) 안내 페이지 찾은 뒤에 넣기
- DB에 국민건강보험법은 있음 (급여정지 조문이 있는지 확인)

### 복무 중 부상 → 보훈 등록 (참고, 대부분 있음)
- 공무상 부상·질병이면 국가유공자(공상군경) 또는 보훈보상대상자(재해부상군경) 등록 → 상이등급 신체검사
- DB: 등록 신청 안내(보훈부 페이지), 상이등급·신체검사·의병전역 관련 법령해석 다수 있음
- 빠진 것: 위의 **등록 전 진료비(전역 6개월 이내 신청)**, 이의신청 기한(블로그는 60일, 공식 확인 필요)
