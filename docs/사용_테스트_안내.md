# 전역도우미 사용·테스트 안내

직접 써 보며 확인하는 순서입니다. 각 단계에 "이렇게 되면 정상"을 적어 두었습니다.

## 0. 켜기

```bash
docker compose up -d
```

- 브라우저에서 http://localhost:3000 을 엽니다.
- 처음부터 해 보려면 **새 시크릿 창**을 쓰세요. 사용자 구분은 브라우저마다 만드는 익명 ID라서, 새 창이면 새 사람입니다.
- 서버 상태 확인: http://localhost:3000/api/health 에서 `agent_ready: true`면 실제 AI로 답합니다.
  `false`면 '데모' 표시와 함께 예시 답만 나옵니다.
- 백엔드 키는 `backend/.env`에 있어야 합니다 (Gemini, 법령 API, 공공데이터포털, 온통청년).

## 1. 처음 온 사람: 전역이가 먼저 묻기 (작전실)

| 해 볼 것 | 이렇게 되면 정상 |
|---|---|
| 새 시크릿 창으로 접속 | 왼쪽 수첩 '전역 생활 작전실'에서 전역이가 "어떻게 복무했어요?"라고 묻고, 복무 형태 버튼 4개가 보임 |
| **의무복무 병사** 누르기 | 2초 안팎으로 짧게 답하고 **시·도 버튼 17개**가 나옴 (검색 안 함) |
| **서울** 누르기 | 전역일을 묻고 **연도 버튼**이 나옴 |
| **2025년 전역** 누르기 | "작전도를 만들고 있어요" 후 20~30초 뒤 **"작전도 완성! 임무 N개"**와 첫 임무, [했어요] [어떻게 해요?] [나중에 할게요] 버튼 |
| 오른쪽 수첩 '나의 전역 작전도' | 계급 카드(이병), 계급 줄, 남은 임무 목록(별표=핵심, 기한 D-day), 훈장 줄이 채워짐 |

## 2. 임무 따라가기

| 해 볼 것 | 이렇게 되면 정상 |
|---|---|
| **어떻게 해요?** | 15초쯤 걸려 자료를 찾고, 노란 말풍선에 "지금 할 일" 한마디, 그 아래 **자세히 보기(혜택·근거 개수)**가 접혀 있음 |
| 자세히 보기 펼치기 | 혜택 카드, 근거 법령, 출처 링크, 피드백 버튼 |
| **작전도에 담을까요?** 상자 | 핵심 임무는 미리 체크됨. 체크를 바꾸고 **N개 담기** → "N개 담았어요", 오른쪽 목록에 들어감 |
| 위쪽 **지금 할 일** 카드의 **했어요** | 그 임무가 완료되고 계급·진행 막대가 바뀜(1개면 일병), 첫 훈장 축하, 전역이가 **다음 임무**를 권함 |
| **나중에 할게요** | 그 임무를 건너뛰고 다른 임무를 권함 (완료되지는 않음) |
| 오른쪽 목록 체크박스 | 채팅 없이 바로 완료/취소 |

## 2-1. 되돌리기

| 해 볼 것 | 이렇게 되면 정상 |
|---|---|
| 임무를 완료하거나 빼거나 담으면 | 화면 아래에 10초 동안 "‘…’ 완료 [되돌리기]" 알림이 뜸. 누르면 바로 원래대로 |
| 임무를 **X로 뺀 뒤** 되돌리기 | 완료 여부, 핵심 표시, 출처까지 그대로 다시 나타남 |
| 작전도 화면 아래쪽 **변경 기록** | 최근 변경이 최신순으로 나열됨. "여기까지 N개 되돌리기"를 누르면 그 항목까지 한꺼번에 되돌림 (중간에 방향을 틀 때) |
| 임무 1개만 완료 | 일병이 됨. 민간인은 핵심 임무를 모두 끝내고 병장 수준(8개)까지 끝내야 됨 |

## 3. 자유롭게 물어보기 (RAG)

입력창에 직접 물어봅니다. 자료를 찾아 근거와 함께 답해야 합니다.

- "군복무 크레딧은 따로 신청해야 하나요?" → 국민연금법 제18조 근거
- "서울 사는 25살인데 월세 지원 받을 수 있어요?" → 청년 월세 관련 혜택
- "국가유공자 등록하려면 서류 뭐 필요해요?" → 보훈 법령, 관할 보훈청
- "혜택 알려줘" (복무 형태를 모를 때) → 되묻지 않고 병사 기준으로 구체적인 혜택(군복무 크레딧 등)과 근거를 보여 줌. 첫 문단에 "의무복무 병사 기준"이라고 밝힘
- "안녕하세요", "고마워요" → 검색 없이 짧게 답하고 다음 임무를 권함

확인할 점:
- 답변에 [1]처럼 근거 번호가 붙는지
- 내 조건(병사·서울)에 맞지 않는 혜택이 섞이지 않는지 (예: 장기복무 전용 혜택)
- '어떻게', '서류', '자격', '신청' 같은 말이 들어간 질문은 항상 자료를 찾는지

## 4. 다시 왔을 때

| 해 볼 것 | 이렇게 되면 정상 |
|---|---|
| 같은 창에서 위의 **전역도우미** 로고 또는 **새 대화** | 전역이가 "어서 와요, 일병님! 다음 임무는 …"과 기한(D-day)을 먼저 말함 |
| 브라우저를 껐다 켜서 다시 접속 | 작전도와 내 조건이 그대로 남아 있음 |

## 5. 작전도 화면 (위 메뉴 '작전도')

- 계급 카드와 계급 줄(이병 → 일병(1개) → 상병(4개) → 병장(8개) → 민간인(핵심 임무 모두 완료))
- 단계 지도: 단계 아이콘을 누르면 그 단계로 이동
- 훈장 8개: 받은 것은 금빛, 아직이면 점선. 이름 아래에 받는 조건이 적혀 있음
- 임무 카드: 근거 링크, **이 단계 진행하기**(채팅으로 이어서 물어봄), 마우스를 올리면 X로 빼기
- **내 정보로 임무 더 찾기**: 내 정보로 임무를 더 모음 (20초쯤)

## 6. 내 정보

- 복무·나·전역 후 계획·보훈·건강·메모를 적고 **저장하기**. 위의 '채운 정도'가 올라감
- 저장한 뒤 **이 정보로 작전도 만들기**
- 희망 직무·자격증을 적은 뒤 채팅에서 "취업 지원 뭐 있어요?"라고 물으면 그 분야 쪽으로 찾는지 확인

## 7. 화면

- 오른쪽 위 달/해 버튼: 어두운 화면 ('야간 작전')
- 휴대폰 크기(개발자 도구 → 기기 모드, 390px): 오른쪽 수첩 대신 **아래 탭바**(작전실 · 작전도(계급 진행) · 내 정보 · 사용법 · 새 대화)

- 위 메뉴 **사용법**(모바일은 아래 탭바): 이렇게 쓰는 법, 눌러 보면 바로 물어보는 예시 문장, 계급 규칙, 알아 둘 점
- 쳐 볼 질문이 더 필요하면 [테스트 질문 모음](테스트_질문모음.md)

## 8. 개발자용 확인

```bash
cd backend && uv run pytest -q
```

```bash
cd backend && uv run jeonyeok-eval
```

```bash
cd frontend && npx vitest run
```

- `pytest`: 백엔드 테스트 191개
- `jeonyeok-eval`: 답변 평가 56문항, 15~20분 걸림, 결과는 `backend/data/eval/results/`
- `vitest`: 프런트 테스트 43개

## 알려진 한계

- 첫 작전도 만들기와 '내 정보로 임무 더 찾기'는 20~30초 걸립니다.
- 임무 문장이 복무 형태와 어긋날 때가 있습니다 (예: 병사에게 "5년 이상 복무하셨다면").
- 대화에서 프로필을 읽는 것이 가끔 흔들립니다 (예: '병장 전역자'를 병사로 못 읽음). 내 정보에서 직접 고르면 확실합니다.
- 로그인이 없어서 브라우저(익명 ID)가 바뀌면 다른 사람으로 봅니다.
