# 다음 방향 토론 (2026-10-27)

> 사용자가 던진 질문: 모델을 한 단계 더 낮추고 다른 걸 높여도 되나? RAGAS 말고 다른 평가 라이브러리로도 테스트해 볼까? 그 밖에 어떤 방향이 있나?
> Claude 세션 3곳이 따로 의견을 내고, 서로의 의견에 한 번씩 반박했습니다(2라운드). 아래는 그 결과입니다.
> 참여: 지원 준비 세션(A), 비판 담당 세션(B), 이 레포 작업 세션(C). 채용 관점 세션에도 보냈지만 권한 설정이 달라 전달되지 않았습니다.

## 결론 한 줄

**모델을 바꾸거나 평가 도구를 늘리기 전에, 지금 평가가 믿을 만한지부터 확인한다.**
지금 점수(202/205, 근거 충실도 0.879)는 키워드 규칙과 "답을 만든 모델과 같은 모델"이 채점한 값이라, 모델을 바꿔도 점수가 안 움직이면 그게 품질이 같아서인지 채점이 둔해서인지 알 수 없습니다.

### 1. 모델을 낮추고 다른 걸 높이기 → 보류 (측정기 확인 뒤에)

### 2. RAGAS 말고 다른 평가 라이브러리 → 방향을 바꿔서 할 만함

| | |
|---|---|
| 합의 | 문제는 라이브러리가 아니라 **채점 모델이 답변 모델과 같은 gemini-2.5-flash**라는 점(자기 채점 편향). DeepEval·TruLens로 바꿔도 채점 모델이 같으면 같은 편향을 여러 번 확인할 뿐이고, 지표 정의도 라이브러리마다 달라 서로 비교가 안 됨 |
| 갈린 점 | A는 DeepEval 하나 추가(pytest 통합)를 제안. B는 그것도 채점 모델이 같으면 의미 없다며 반대 → **라이브러리 추가보다 채점 모델 교체가 먼저**로 정리. LangSmith·Phoenix·TruLens는 평가보다 추적·관측 도구라 지금은 보류 |
| 실험 | ① 무작위 30문항을 사람이 직접 0/1/2점으로 채점 ② 같은 30문항을 다른 계열 모델(Claude·GPT 계열, 최소 gemini-2.5-pro)로 RAGAS 재채점 ③ 사람 점수와의 일치도, 그리고 "같은 모델이 채점하면 몇 점 후하게 주는가"를 표로 |
| 포트폴리오 가치 | "RAGAS 0.879"라는 숫자 하나보다 **"자기 채점은 X점 부풀렸고, 사람과 가장 잘 맞는 채점자는 Y였다"** 가 훨씬 강한 근거라는 데 셋 다 동의 |
