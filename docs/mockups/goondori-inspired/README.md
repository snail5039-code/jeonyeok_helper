# 군돌이 모티브 목업

**상태: 최종 선택 시안 (2026-10-16)**

확정된 방향: 자연어 질문을 메인으로 두고, 전역 전/후에 맞춰 오른쪽 작전도와 같은 여성 인물의 사진이 함께 바뀝니다. 군 컨셉과 노란 테두리 버튼의 B급 감성은 유지합니다.

기존 `balanced-direction/home-bplus.html`을 유지하면서 별도로 만든 정적 디자인 시안입니다. 군돌이의 개인 프로필과 진행 상태를 한눈에 보여주는 카드 형식을 참고했습니다. 카드의 내용은 전역 전/후에 따라 달라지고, 자연어 질문창은 메인에 그대로 둡니다. 상태 탭은 목업 확인용입니다.

전역 전에는 군복 차림, 전역 후에는 사복 차림의 같은 여성 인물이 메인 사진과 프로필 사진에 표시됩니다. 두 사진은 이 목업을 위해 생성한 이미지입니다.

화면의 인물, 날짜, 진행률, 질문은 모두 예시입니다. 군돌이 로고와 화면 이미지를 복제하지 않았으며, 서비스 기능은 구현하지 않았습니다.

- `index.html`: 목업 화면
- `desktop.png`: 데스크톱 미리보기
- `desktop-after.png`: 전역 후 상태 미리보기
- `mobile.png`: 모바일 미리보기
- `mobile-after.png`: 전역 후 모바일 미리보기
