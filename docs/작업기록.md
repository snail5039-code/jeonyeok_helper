### 10-12 점검: 실제 질문으로 검색 시험, 중복 정리

**중복·불필요 코드 정리**
- 지역 이름 처리가 5곳(gov24·법령 API·위탁병원·청년정책·채용·보훈관서)에 흩어져 있던 것을 `benefits/regions.py` 하나로
- '전체 목록 받기 + 시간 캐시'가 4곳에 따로 있던 것을 `benefits/common.py`의 `TimedCache`·`fetch_all_pages`로
- 법령 API 호출 4개, 조례·해석례 페이지 넘기기, 법령·행정규칙 수집 반복문, 도구 원문 직렬화, 클라이언트 팩토리 4개를 각각 하나로
- 프론트엔드 POST 요청 3곳(채팅·피드백·로드맵)을 `lib/api.ts`의 `postJson`으로

**실제로 찾은 버그**

| 문제 | 원인 | 해결 |
|---|---|---|
| '부산 해운대', '전남'처럼 말하면 지자체 혜택이 **0건** | 지역을 통째로 한 문자열로 비교, 2026년부터 전남 기관명이 '전남광주통합특별시' | 시도·시군구로 나눠 비교, 같은 시도 표기 인정. 전남 0 → 17건 |
| 전남·광주 조례 **696조문**이 검색되지 않음 | 저장된 시도 값이 '전남광주통합'·'(구)광주' | 통합 전후 이름을 모두 보는 `province_variants` |
| 전남·광주 사용자에게 청년정책 **0건** | 통합 후 정책은 새 지역 코드 12 | 코드표에 12 추가 (463건 다시 보임) |
| 평가가 서비스와 다른 설정으로 돌아감 | 평가만 온도 0.2, 생각 예산 기본값 | 서비스·로드맵·평가가 같은 `get_answer_model()` 사용 |
| '작년에 전역' → 2023년으로 저장 | 프로필 추출이 오늘 날짜를 모름 | 프롬프트에 오늘 날짜 |
| 병사에게 '국가유공상이자 교통시설 이용지원' | 보훈 전용 판별 패턴이 '국가유공자'만 봄 | '국가유공', '상이자' 등으로 넓힘 |

**검색 시험 (실제 질문 34개)**: 예비군·연금·호봉·응시연령·학비·주택·창업 등은 근거 조문이 1~2위로 나옴.
근거 법령이 아예 없던 주제를 찾아 **법령 9개(조문 70개)** 추가: 구직자취업촉진법(국민취업지원제도)과 시행령,
고용보험법(구직급여 요건), 고용보험법 시행령(병역 시 수급기간 연기), 국민건강보험법(현역병 급여 정지·피부양자),
도로교통법·시행령(군 복무 중 면허 갱신 연기), 공무원임용시험령(전역예정자 응시), 주택공급에 관한 규칙(특별공급).

## 주요 결정과 이유

| 결정 | 이유 |
|---|---|
| LLM은 **Gemini** | 사용자가 보유한 키. 기본 2.5 Flash, 필요하면 3.5로 교체 |
| 기술 스택은 **AI.M 1기 AI 에이전트 엔지니어 트랙** 기준 | LangGraph 멀티에이전트, MCP, RAG(HyDE·Re-ranking), FastAPI, Docker, CI/CD |
| 대상은 **전역자 전체 유형** | 병사·단기 간부·중장기·보훈대상자. 유형마다 혜택이 달라 프로필로 먼저 구분 |
| 프로필은 **대화 중에 묻기** | 정보가 부족할 때만 되묻고, 받은 정보는 장기 메모리에 저장 |
| **MCP 1.x 고정** | LangChain MCP 어댑터가 MCP 2.x를 아직 지원하지 않음 |
| 화면은 **Next.js** (Flutter 아님) | 링크로 바로 쓰는 웹이 전역자 사용 패턴에 맞고, 검색·공유에 유리 |
| Next.js → FastAPI는 **Route Handler 프록시** | 실행 시 `API_URL`을 읽어 이미지 하나로 배포 가능, SSE를 버퍼링 없이 전달 |
| **LangSmith 대신 평가 데이터셋** | 사용자 요청. 30문항을 근거 출처·답변 핵심어·프로필·되묻기로 채점 |
| 평가는 **정답 문장이 아닌 근거와 행동** 기준 | 금액·기한은 법령 개정으로 바뀌고, 기준을 잘못 적으면 그 자체가 오류가 됨 |
| 모델은 **2.5 Flash 유지** | 데이터를 넣은 뒤 30/30이 나와 3.5로 올릴 이유가 없음 |
| **조례는 사용자 지역 것만 검색** | 지자체마다 비슷한 조례가 수백 개라 섞으면 법령이 밀려남. 지역을 모르면 법령만 |
| **행정규칙은 이름으로 골라 수집** | 보훈부·국방부 훈령 대부분이 내부 운영 규정이라 키워드 수집은 잡음이 많음 |
| **지자체 장학금은 제외** | 약 1,000건이지만 운영 지역을 안정적으로 알 수 없어 지역 필터를 못 검. 전국·군 관련 148건만 |
| 전체 목록을 받아 **캐시하고 직접 거름** (위탁병원·나라사랑가게·청년정책) | 이 API들은 지역 조건 검색이 없음. 하루(청년정책은 12시간) 캐시 |
| 보훈관서 주소록은 **직접 정리한 YAML** | 공개 API가 없어 국가보훈부 누리집 관서별 페이지에서 수집 |
| **워커는 도구를 반드시 부르고, 결과를 다시 요약하지 않음** | 답변·검증은 도구 원문(evidence) 기준. 요약은 시간만 들고, 도구 없이 답하면 근거가 없어 검증에서 지워짐 |
| **답변 생각 예산 1024** | 평가 비교: 기본값 30/30 27초, 1024 30/30 21초, 0 29/30 18초('혜택 다 알려줘'에 답이 좁아짐) |
| **스트리밍은 초안 → 검증본 교체** | 검증 전 초안을 먼저 보여 주되, 근거 확인이 끝나면 최종 답으로 바꾸고 그때 출처를 붙임 |
| 전직교육원 안내서는 **받지 않음** | 내려받으려면 사이트 이용약관 동의가 필요하고 2022년 자료라 오래됨 |

## 실제로 돌려 보며 찾은 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 질문을 보내도 첫 화면이 사라지지 않음 | 아이콘 `<symbol id="home">`과 화면 영역 `id="home"`이 겹침 | 아이콘 id에 `ic-` 접두어, id 중복 검사 테스트 |
| 장기 메모리(프로필)가 저장되지 않음 | `from __future__ import annotations`가 있으면 LangGraph가 노드에 저장소를 주입하지 못함 | 해당 파일에서 제거하고 주석으로 기록 |
| 답변 카드가 깨짐 (줄바꿈 사라짐) | 근거 검증 단계가 답변을 다시 쓰며 줄바꿈을 날림 | 문제가 없으면 초안을 그대로 사용 |
| 3.5가 근거 없는 혜택·금액·연락처를 지어냄 | 검증이 도구 원문이 아니라 워커 요약을 기준으로 함 | 도구 원문(evidence)을 답변·검증의 기준으로 |
| 법령 API "사용자 정보 검증 실패" | OC 값이 실제 계정과 다름 (IP 등록은 정상) | 사용자가 OC를 바로잡아 해결 |
| 검색 시 "Error loading hnsw index" | Windows에서 경로에 한글이 있으면 Chroma가 인덱스 파일을 쓰지 못함 | 한글 경로면 `LOCALAPPDATA` 아래 영문 경로에 저장 |
| 지역 필터가 다른 지역 혜택을 못 거름 | 실제 소관기관유형은 `시군구`·`광역시도`인데 '지방'이라는 글자로 찾음 | 실제 값으로 구분 |
| 조례 3개 저장 실패 | 한 조례 안에 같은 조문 번호가 두 번 나옴 | 같은 번호는 본문을 이어 붙여 하나로 |
| 라우터가 법령 질문에 검색 없이 바로 답함 | 빠른 설정(생각 끔) 라우터의 판단 | '워커 없이 answer 금지', 자격·기간 질문은 규정 검색 규칙 |
| 동시에 돌린 워커가 서로를 기다림 | MCP 도구가 동기 함수라 이벤트 루프를 막음 | 도구를 스레드에서 실행 |
| 브이넷 채용 지역이 엉뚱하게 나옴 | 공식 안내의 지역 코드표가 실제 응답과 다름 (4가 부산이 아니라 인천) | 1~18을 모두 호출해 확인한 코드로 |
| 나라사랑가게 호출 방법을 알 수 없음 | 포털 상세 페이지 명세가 비어 있음 | 페이지에 숨어 있던 Swagger 명세에서 오퍼레이션 확인 |
| 온통청년 403 | 기본 User-Agent(python-httpx)를 막음 | 브라우저 User-Agent 사용, 오류 메시지에서 인증키 URL 제거 |
| 자료를 늘린 뒤 30/30 → 24/30 | ① 606조각 안내서가 법령을 밀어냄 ② 워커가 도구 없이 답해 검증에서 답이 지워짐 ③ '병역필' 요건을 군 관련으로 봄 | 같은 문서는 검색 결과 2개까지, 워커 도구 호출 강제, '병역' 제외 |

## 지금 구조

```
브라우저 ─▶ Next.js (frontend) ─/api/*─▶ FastAPI (backend, SSE: step → delta → answer)
                                           └─ LangGraph 슈퍼바이저
                                                ├─ 프로필 추출 (빠른 설정)
                                                ├─ 라우팅 (빠른 설정, 혜택 질문은 규정도 함께 동시 실행)
                                                ├─ 규정 워커 ─ MCP ─ RAG (Chroma, HyDE, Re-ranking, 같은 문서 2개까지)
                                                │                  법령·행정규칙·해석례·조례(지역)·민원·장학금·안내서
                                                ├─ 혜택 워커 ─ MCP ─ 정부24 혜택, 온통청년, 브이넷 채용, 나라사랑가게
                                                ├─ 기관 워커 ─ MCP ─ 기관 링크 DB, 관할 보훈관서, 보훈 위탁병원
                                                ├─ 답변 작성 (도구 원문 기준, 생각 예산 1024, 스트리밍)
                                                └─ 근거 검증 (도구 원문 기준, 문제 있을 때만 다시 씀)
대화 기록·프로필: SQLite / 실행: Docker Compose / CI: GitHub Actions
```
