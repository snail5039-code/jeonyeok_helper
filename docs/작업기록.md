## 주요 결정과 이유

| 결정 | 이유 |
|---|---|
| LLM은 **Gemini** | 사용자가 보유한 키. 기본 2.5 Flash, 필요하면 3.5로 교체 |
| 기술 스택은 **AI.M 1기 AI 에이전트 엔지니어 트랙** 기준 | LangGraph 멀티에이전트, MCP, RAG(HyDE·Re-ranking), FastAPI, Docker, CI/CD |
| 대상은 **전역자 전체 유형** | 병사·단기 간부·중장기·보훈대상자. 유형마다 혜택이 달라 프로필로 먼저 구분 |
| 프로필은 **대화 중에 묻기** | 정보가 부족할 때만 되묻고, 받은 정보는 장기 메모리에 저장 |
| 지자체 조례는 **MVP 포함** | 병사 전역자 혜택은 지자체 비중이 큼 (실제 응답 형식 확인 후 수집기 작성 예정) |
| **MCP 1.x 고정** | LangChain MCP 어댑터가 MCP 2.x를 아직 지원하지 않음 |
| `create_react_agent` → **`create_agent`** | LangGraph 1.0부터 deprecated |
| 화면은 **Next.js** (Flutter 아님) | 링크로 바로 쓰는 웹이 전역자 사용 패턴에 맞고, 검색·공유에 유리. 앱은 나중에 같은 API에 추가 가능 |
| 메뉴는 **위쪽 바** | 사용자 요청. 모바일은 위에서 펼쳐지는 메뉴 |
| Next.js → FastAPI는 **Route Handler 프록시** | 실행 시 `API_URL`을 읽어 이미지 하나로 배포 가능, SSE를 버퍼링 없이 전달, 허용한 경로만 통과 |
| **LangSmith 대신 평가 데이터셋** | 사용자 요청. 30문항을 근거 출처·답변 핵심어·프로필·되묻기로 채점 |
| 평가는 **정답 문장이 아닌 근거와 행동** 기준 | 금액·기한은 법령 개정으로 바뀌고, 기준을 잘못 적으면 그 자체가 오류가 됨 |
| 모델은 **2.5 Flash 유지** | 지금은 데이터가 없어 3.5도 기관 안내밖에 못 하는데 시간은 두 배. 법령 수집 후 재비교 |
| **ORM은 보류** | 직접 쓰는 SQL이 없음. 피드백 저장을 넣을 때 SQLAlchemy 2.0 + Alembic 도입 예정 |

## 실제로 돌려 보며 찾은 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 질문을 보내도 첫 화면이 사라지지 않음 | 아이콘 `<symbol id="home">`과 화면 영역 `id="home"`이 겹침 | 아이콘 id에 `ic-` 접두어, id 중복 검사 테스트 추가 |
| 장기 메모리(프로필)가 저장되지 않음 | `from __future__ import annotations`가 있으면 LangGraph가 노드에 저장소를 주입하지 못함 | 해당 파일에서 제거하고 주석으로 기록 |
| 답변 카드가 깨짐 (줄바꿈 사라짐) | 근거 검증 단계가 답변을 다시 쓰며 줄바꿈을 날림 | 문제가 없으면 초안을 그대로 사용 |
| **3.5가 근거 없는 혜택·금액·연락처를 지어내고 출처 번호를 붙임** | 검증이 도구 원문이 아니라 워커 요약(지식이 섞인)을 기준으로 함 | 도구 원문(evidence)을 따로 보관해 답변·검증의 기준으로 사용, 워커 프롬프트에 "원문에 없는 내용 금지" |
| 같은 기관이 출처에 두 번씩 나옴 | 여러 워커가 같은 기관을 찾음 | 출처 중복 제거 |
| 응답이 평균 35초, 최대 79초 | 단순한 판단 단계에서도 '생각' 단계를 거침, 같은 워커를 반복 호출, 빈 법령 DB에도 HyDE 호출 | 판단 단계는 생각 끈 빠른 설정, 워커당 최대 2회, 빈 DB는 바로 반환 |
| 혜택 조회 실패 시 항상 같은 기관만 안내 | 대체 안내가 고정 목록 | 질문 주제에 맞는 기관(취업 → 고용24)을 먼저 안내 |
| `?q=` 공유 링크가 서버가 정상일 때 동작 안 함 | 데모 여부가 바뀌지 않으면 효과가 다시 실행되지 않음 | 별도 '준비 완료' 상태로 실행 |

## 평가 결과 (Gemini 2.5 Flash, 법령·혜택 데이터 없이)

| | 처음 | 개선 후 |
|---|---|---|
| 전부 통과 | 17 / 30 | **22 / 30** |
| 체크 통과율 | 82% | **90%** |
| 평균 응답 시간 | 35초 | **15초** |

- 되묻기, 프로필 추출(복무 형태·지역·기간)은 100% 통과
- 남은 실패 8건은 모두 법령(예비군법, 군인연금법, 제대군인지원법, 국가유공자법 등)이 출처로 나와야 하는 항목 → **법령 수집 후 해결 예정**
- 데이터가 없을 때 지어내지 않고 "현재 자료에서 확인할 수 없다"고 답하는 것을 확인

## 지금 구조

```
브라우저 ─▶ Next.js (frontend) ─/api/*─▶ FastAPI (backend)
                                           └─ LangGraph 슈퍼바이저
                                                ├─ 프로필 추출 (빠른 설정)
                                                ├─ 라우팅 (빠른 설정, 워커당 최대 2회)
                                                ├─ 규정 워커  ─ MCP ─ RAG (Chroma, HyDE, Re-ranking)
                                                ├─ 혜택 워커  ─ MCP ─ 공공서비스 API (실패 시 주제별 기관 안내)
                                                ├─ 기관 워커  ─ MCP ─ 기관 링크 DB
                                                ├─ 답변 작성 (도구 원문 기준)
                                                └─ 근거 검증 (도구 원문 기준, 빠른 설정)
대화 기록·프로필: SQLite / 실행: Docker Compose / CI: GitHub Actions
```
